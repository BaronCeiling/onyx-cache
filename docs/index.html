What it does

  • Static page cache for guests — exclusions, TTL, purge from the admin bar or WP-CLI
  • HTML/CSS/JS minification, emoji and embed cleanup, async image decoding
  • WebP and AVIF copies generated on upload, served automatically
  • Database maintenance: revisions, spam, orphan meta, expired transients, table sizes
  • Sitemaps, Open Graph cards, breadcrumbs, JSON-LD
  • 404 log with hit counts and one-click permanent redirects

Install

# WP-CLI
wp plugin install https://github.com/BaronCeiling/onyx-cache/releases/latest/download/plugin.zip --activate

# or from source
cd wp-content/plugins && git clone https://github.com/BaronCeiling/onyx-cache.git onyx-cache

# or: Plugins → Add New → Upload Plugin → choose plugin.zip
