# FAQ

### Does Onyx Cache replace my current cache plugin?
Run one at a time. Deactivate the other, purge once, then compare two pages: the front
page and a paginated archive.

### Where does the cache live?
`wp-content/cache/onyx-cache`. Deleting that directory by hand is safe.

### Can it run without WP-CLI?
Yes. Everything the CLI does is a button on the admin screen.
