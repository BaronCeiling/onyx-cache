Free page cache plugin: what actually differs

Most paid caching plugins sell the same four things: page cache, minification, image conversion and a CDN. The differences that matter in practice are narrower — whether the cache covers the pages you care about, whether the settings screen explains what it just did, and whether the plugin phones home. Onyx Cache is MIT licensed, works without an account, and shows its own counters instead of a score.

Where a free plugin is genuinely enough

A brochure site, a blog, a small shop on one server: a page cache plus image conversion plus a database cleanup is the whole job. That is what Onyx Cache does, and the dashboard counts hits, misses and bytes saved so you can confirm it is working.

What a paid plan usually adds

Edge CDN delivery, a larger exclusion rule set, image CDNs, and support. If your traffic is regional and your host is decent, the first two rarely move a number you can measure; a CDN helps most when visitors are far from the server.

Decide by measurement, not by feature count: record time to first byte with the plugin off, then on. If the difference is under 100 ms, the plugin is not your bottleneck.

The exit cost nobody mentions

Caching plugins write into wp-config, add drop-ins and leave rules behind. Onyx Cache ships a clean uninstall: options, transients, the cache directory and its tables go away, and the site behaves as if it was never installed.

Watch the ratio rather than the total: hits divided by requests, over a day. A cache that serves 60% of requests is doing something; 95% means it is covering the site. The same screen shows cache size and the oldest entry, which tells you whether the TTL matches how often the content actually changes.

If the ratio is high and the site still feels slow, the problem is downstream of PHP: images, fonts, or a host network that is saturated. That is the point at which a CDN becomes the right answer, and the counters here are how you know you have reached it.

Who this is for

The useful test: do you administer the site yourself, and does it run on hosting you can restart? If yes, Onyx Cache is the whole performance stack. If someone else owns the platform and the CDN, the plugin is a smaller piece of a larger puzzle and the counters here will tell you how much of the problem was yours to begin with.

What it does not do

No CDN. No image CDN. No edge computing, no page builder, no backup, no security firewall. Onyx Cache does not rewrite your theme, does not inject a dashboard banner asking for a review, and does not phone home unless the administrator ticks the box on the dashboard. If a feature needs a remote service to work, it does not belong in a cache plugin.

Frequently asked

Is a free cache plugin slower than a paid one?

The cache itself is the same idea; what differs is polish and add-ons. Measure TTFB before and after — that number decides, not the price.

Do I need a CDN as well?

Only if your visitors are geographically far from the server or your host throttles. A page cache on the origin fixes render time; a CDN fixes distance.

What happens if I uninstall it?

Onyx Cache removes its options, transients, cache directory and tables. No drop-in is left behind.
